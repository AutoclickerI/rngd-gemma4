# Opt 0.9.0 rules and pitfalls

## Vector, contraction and packet rules

- One use per ALU per vector pass (reuse panics with `{alu:?} is already in use`). `AddF`/`SubF` share `FpFma`, `DivF` uses `FpFpu`, and `MulF` uses its named multiplier. Split repeated adds and the GeGLU/residual/quantization sequence. `begin_interleaved` shares one dtype across both operands. Cast first or split passes. `furiosa-opt-std-0.9.0/src/engine/vector/stage/state.rs:32`, `furiosa-opt-std-0.9.0/src/engine/vector/op/mod.rs:232-237`, `furiosa-opt-std-0.9.0/src/context.rs:95-101`.
- Contractions pair matching float types or integer types within `{i4,i5}` or `{i8,i9}`. Decode or stage 4-bit weights before F8 contraction. `fetch_table_lookup` decodes public F4 (E2M1) on Main. Commit to DM and stage to TRF via Sub. Use `fetch_zero_point_sub` for the `i4` → `i5` and `i8` → `i9` staging conversions. Single-pass W4A5 rejected `RawInt5, collect_flits: Flit2`. Two-plane and i8-container forms use other producers. `furiosa-opt-std-0.9.0/src/cast.rs:346-377,44-50,88-95`, `furiosa-opt-std-0.9.0/src/engine/fetch_adapter.rs:178-182`, `furiosa-opt-std-0.9.0/src/scalar.rs:780-784`.
- Size `contract_packet` by input storage bytes (one or two flits), including for FP8 (`E0080` on accumulator-bit sizing). Output is a power-of-two element count within accumulator width and preserves the mapping prefix. For `Packet(W0%2,D%32)` → `D%32`, physically interleave, fetch `[D16,W2]`, form `[D32,W2]`, then reduce inner `W2`. Two native FP8 prefill fixtures saved 8.3/9.8 µs per launch with zero output-byte changes. `furiosa-opt-std-0.9.0/src/engine/contraction/packet.rs:31-34`, `furiosa-opt-lower-0.9.0/src/verify/engine/contraction/packet.rs:34-35`.
- Collect matches the incoming packet mapping and requires one 32 B flit. Eight BF16 elements (16 B) need `Lu%8 # 16`, then `commit_trim`. Keep a full `Kb % 16` packet throughout. Trim padding is typed in elements (`m![W % 4 # 8]` has four live elements, 4 B F8 or 8 B BF16). Match the trimmed run to the DM innermost run, e.g. use eight live F8 elements with `# 32` before trimming to `W0 % 8`. `W0 % 4 # 32` fails commit projection. [Collect](../src/device/tokenwise_int8/ffn_fast.rs), [FP8 transpose](../src/ops_dsl_attention/prompt_pattn.rs), `furiosa-opt-std-0.9.0/src/constraints.rs:112`, `furiosa-opt-lower-0.9.0/src/verify/engine/collect.rs:21`, `furiosa-opt-lower-types-0.9.0/src/commit.rs:27-34`.
- Transpose output is 32 B (use `# 32` for sixteen F8 elements). Row evidence comes from `Time`. Beyond `max_in_rows (8)`, use `1 # n` pure padding. Put the key axis in `Time` with pure-padding input `Packet`, emit eight live F8 elements padded to 32 B, trim to 8 B. `furiosa-opt-lower-types-0.9.0/src/transpose.rs:46,68,147`.
- For `contract_outer`, `OutTime` follows the outer `Time` with broadcast axes innermost. For PV, use `(D/32, W/128, W%2)` with `time0 = 2`. Adding `D/32 % 2` with `time0 = 4` fails. `furiosa-opt-lower-0.9.0/src/verify/engine/contraction/outer/stream_adapter.rs:32`.
- To narrow after `vector_init`, tag with `vector_intra_slice_tag(TagMode::Zero)`, then `vector_narrow_split` to `Way4`. `vector_fp_binary` takes `Tag`, `Logic`, `Fxp`, `FxpToFp`, `Narrow` or `Fp`. On `IntraSliceReduce: CanTransitionTo<Fp>` (`E0599`), move the op before reduction, dedicated divide or widen when valid (positive scale before max), or split passes. [Sampler](../src/ops_sampler.rs), `furiosa-opt-std-0.9.0/src/engine/vector/stage/markers.rs:252-257`, `furiosa-opt-std-0.9.0/src/engine/vector/tensor/vector_tensor.rs:1309-1374`.

## Mapping and allocation

- Indirect indices must be dense, one per position spanned per pass. Preserve the mapping of a tiled view (`LowLevelReshape` rejects it) and pad the unit axis in the producer or interleave. `furiosa-opt-lower-0.9.0/src/verify/indirect.rs:30,53-57`.
- Tile only in-slice axes. Move Cluster or Partitioning into `Element` via typed copy or `InterTranspose`. CPU comparison matched all 2,097,152 values, with extra Main and transfer work. DM must span all configured clusters/slices (e.g. 2/256, whereas extents 1/232 failed). Select slices in the backing mapping.
- Fetch stored axis identities and project explicitly, or tile directly on the target axis. Equal extents do not make `Lp` and `Lu` interchangeable (`E0308` or unread live axis). In `m!`, brace const expressions and composite aliases (`{M_alias}`) to avoid `E0747`. `furiosa-opt-lower-types-0.9.0/src/fetch.rs:56`.
- Compile axes/tiles per row bucket. Down uses `PS = 2 * HALF`. Two passes use `T = 2 * PS` (1,280 rows with `PS = HALF = 256` failed `E0080`). The current 1,536-row quarter split uses three passes. `src/device/tokenwise_int8/core8_full.rs#PS` At 256 query rows use four 64-query blocks `(Q/64%4, Q%64, Q%1)` and true 256-row query/output extents. Four 128-query blocks from the 512-row shape fail `stride must divide the size`, including FP8. [Down shape contracts](../src/device/tokenwise_int8/rowdown_dm8_f8.rs)
- Serialize quarter staging through one mutable DM buffer (`wt.to_dm_view(&mut device.tdma, wd.view_mut())`) to avoid overlapping TRF allocations (`Cannot find evict target for Trf`, 15,728,640 B request). VRF scheduling also needs space beyond the operand. A ~1 KiB/slice stash left a large operand that fit 8,192 B unschedulable (`V1-Modulo` / `Cannot find evict target for Vrf`). Reducing to 64 coefficients at 4,096 B/slice lowered. `furiosa-opt-std-0.9.0/src/constraints.rs:128-138`.
- Main stores through Sub via `.to_vrf(&mut device.sub)` (`E0061` without the borrow). Only owning DM tensors have allocating `to_dm` (`E0599` on views). For views, allocate `DmTensor::new()`, then `view.to_dm_view(..., dst.view_mut())`. Form commit destinations directly as `.view_mut().tile(...)` when a reshaped alias loses mutability (`expected a DmTensorViewMut`). For Sub commits into strided half-tiles that hit the SFR ICE (`sfr_impl.rs:868:33`), commit to whole DM then copy (32 KiB scratch/slice and one copy). [Mutable destinations](../src/ops_dsl_attention/prefill.rs), `furiosa-opt-std-0.9.0/src/engine/collect.rs:91-115`, `furiosa-opt-std-0.9.0/src/tensor/memory.rs:947,1039`.
- `DmaGather` rejects a 2 B FP8 interleave on 8 B alignment (`strides([1, 2, 134217728, 4194304, 1, 1024, 4, 0])`). Use contiguous `[D, J=2]` with an explicit pair index (cache ABI change).
- Order gathers of snapshots before the next pool writer with write-after-read edges, or gather the published version when overlap is unnecessary. Otherwise lowering can see reader version `N-1` for a write at `N`. [Resident pool](../src/ops_core/resident.rs)

## Build, scheduling and launch

- For standalone kernels add an empty `[package.metadata.furiosa-opt]` in `Cargo.toml`. Run `cargo furiosa-opt compile` from the crate directory (the CLI rejects `--manifest-path`). Select exactly one `#[device]` for `--dump-*`. Device assertions must be `const { assert!(..) }`; check runtime data on the host.
- Cache keys can miss macro axis changes and vary by checkout or `build`/`compile`. The wrapper invalidates on literal-axis, axis-size or macro-axis file-set changes, and invalidates dependent kernels on edits inside existing macro-axis files. [Shard builder](../tools/native/shard_build.py) compiles disjoint concrete kernels. [Opt wrapper](../tools/native/opt_build.sh) checks the cache with [the rekey tool](../tools/native/opt_cache_rekey.py).
- `SCHEDULER_MANUAL_ORDERING_PATH` can leave violated edges after graph edits (3/115 remapped, 21/255 chain). Exporting 451 adjacent compute pairs from a solved schedule left 33 reversed and added 36 µs to the static estimate. Enforce exact order by post-pass. [Carried build](../tools/native/prebuilt/build.sh#L62-L70)
- The carried-image build removes TU clock-control pushes and lowers packed Q4 operands to native INT4 with checked contraction and TRF edits. [Task-C tools](../tools/native/fopt/) capture C and rebuild images. [Direct build](../tools/native/fopt/direct_build.py) takes a single-chunk base and Opt headers/library via `--toolroot`. [Relink](../tools/native/fopt/relink.py) converts linked objects to task blobs.
- `queued!(...)?` already awaits on both backends. Adding `.await` gives `E0277`. `src/host/engine/queue.rs#queued`
